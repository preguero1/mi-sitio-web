# HCI – Prueba del Bachelor

## Descripción
Este repositorio contiene una prueba práctica de la asignatura de Interacción Persona-Ordenador (HCI), correspondiente al Bachelor.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Objetivo
Desarrollar una aplicación web aplicando conceptos básicos de interacción persona-ordenador.

## Ejecución
Para ejecutar el proyecto, abrir el archivo `index.html` en un navegador web.
